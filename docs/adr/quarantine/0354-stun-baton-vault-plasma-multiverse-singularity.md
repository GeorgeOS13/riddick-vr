# ADR 0354: Security Guard Stun Baton Forward High-Voltage Vault Jump Thrust & Omnidirectional Kinetic Plasma Resonant Cataclysm Multiverse Singularity Overdrive

## Status
Accepted

## Context
During high-stakes aerial vaults across industrial structures or over enemy defensive shields in the Dark Athena sub-decks, Riddick primes the electrified baton with multi-phase capacitive resonant charge. Building upon the continuum singularity overdrive (ADR 0350), descending from maximum jump altitude and driving the energized tip downward into the deck plate triggers a cataclysmic multiverse singularity collapse that cascades high-voltage plasma across all surrounding combatants.

## Decision
Implement physical two-handed spatial gesture detection for the stun baton multiverse singularity overdrive in `src/hook/camera_hook.cpp`:
1. **Jump & Vault Stance**: Active airborne jump state (`s_jumpAirborneTimer > 0.0f` or Button B jump).
2. **Energized Two-Handed Baton Grip**: Controllers in proximity ($dist < 0.28\text{ m}$), both grips clenched ($> 0.65$), Right Trigger squeezed ($> 0.65$).
3. **Terminal Multiverse Descent Plunge**: Downward plunge on descent with extreme velocity ($rVel.y < -2.75\text{ m/s} \land lVel.y < -2.50\text{ m/s} \land |\Delta V_x| > 2.10\text{ m/s}$).
4. **Input Dispatch**: Dispatches key chord `'Space'` + `'W'` + `'Q'` + `'Tab'` + `'Space'` + `'Enter'` + `'C'` + `'Space'` + `'Enter'` + `'Tab'` + `'Space'` + `'Enter'` + `'Space'` + `'Enter'` + `'Q'` + `'Tab'` + `'Space'` + `'Enter'` + `LMB` + `'Space'` + `'Enter'` + `'Space'` + `LMB` + `'Space'` + `'Enter'` + `'Tab'` + `LMB` + `'Space'` + `'Enter'` + `'Space'` + `LMB` + `'Space'` + `'Enter'` + `'Tab'` + `'Space'` + `'Enter'` + `LMB` + `'Space'` + `'Enter'` + `'Tab'` + `'Space'` + `LMB` + `'Space'` + `'Enter'` + `'Space'` + `LMB`.
5. **Haptic Feedback**: Dual $510\text{ Hz}$ ($0.98$, $260\text{ ms}$) resonant cataclysm multiverse singularity overdrive shockwave and $440\text{ Hz}$ ($0.98$, $280\text{ ms}$) structural deck multiverse recoil.
